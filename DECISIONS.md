# DECISIONS — журнал решений

Каждое решение: что выбрали, почему, альтернативы. Новые записи — внизу.

## D-001. Движок: Godot 4.7.2 stable, GDScript, рендерер Compatibility
- Последний стабильный релиз на GitHub на момент старта (ноябрь 2026).
- Compatibility (OpenGL 3 / WebGL 2) — работает в headless-окружении через xvfb, нужен для web-экспорта и стабильных скриншотов.
- GDScript, а не C#: web-экспорт C# в Godot 4 ограничен, а GDScript не требует .NET.

## D-002. Визуальная проверка: xvfb + `--rendering-driver opengl3`, скриншот через `get_viewport().get_texture().get_image()`
- Проверено на пустом проекте: работает. Критики смотрят PNG-скриншоты.
- Аудио: в контейнере нет ALSA, запускаем с `--audio-driver Dummy`.

## D-003. Ответы владельца перед стартом (07.11.2026)
- Клик не обязателен, но курсор — оружие при наведении (как в референсе).
- Платформа: ПК, горизонтальный экран (база 1280×720), web-сборка + Windows.
- «Своя фишка» из предложенных вариантов (давление пара, автоматоны-рабочие, модульные башни) — не нужна, владельцу не понравились. Не строим игру вокруг них.
- Звук не нужен. Весь отклик — визуальный.

## D-004. Push в GitHub недоступен на старте
- Репозиторий GamerDerp/idle-king пустой, клонирован; push отклоняется (403: нет Claude GitHub App). Владельцу отправлено сообщение.
- Решение: коммитим локально после каждой принятой части и пробуем `git push` каждый раз. История не теряется: при появлении доступа уйдёт целиком. Резерв — git bundle.

## D-005. Числа: 64-битный float (double) + защитные функции, а не собственный BigNum
- Конечная игра на ~5 часов: целевые значения укладываются в 1e100, double держит до 1.8e308 с точностью 15 знаков, этого достаточно.
- Собственный BigNum (мантисса+экспонента) усложнил бы весь код и симуляцию. Защита: `NumFmt` форматирует (1.2K … 999.9Dc, затем 5.6e15-нотация), `Num.safe()` отсекает NaN/inf. Тест на переполнение — в наборе тестов.
- Если симуляция покажет выход за 1e300 — пересмотрим.

## D-006. Логика отделена от отображения
- Ядро (`scripts/core/`) — чистые скрипты без узлов сцены: состояние, экономика, волны, бой, улучшения. Его гоняет и игра, и headless-симуляция с ботом. Так баланс проверяется тем же кодом, что и игра.
- Вид (`scripts/view/`) только читает состояние и сигналы и рисует отклик.

## D-007. Баланс в JSON-конфигах `config/*.json`, тексты в `i18n/strings.csv` (ключ; ru; en)
- Godot импортирует CSV как переводы; `tr("KEY")`. Английский столбец можно заполнить позже.

## D-008. Арт: процедурный пиксель-арт, генерируется Python-скриптом (PIL) в PNG
- `tools/art/gen_art.py` рисует все спрайты из единой палитры (`tools/art/palette.py`) → `assets/sprites/*.png`. PNG коммитятся, скрипт — источник истины. Чужие ассеты не используются.
- Фильтр текстур — nearest, целочисленный масштаб мира.

## D-009. CSV переводов: разделитель — запятая, `.translation` коммитятся
- Импортёр CSV в Godot 4.7 по умолчанию ждёт запятую (`delimiter=0` в `.import`). Заголовок `keys,ru,en`, значения с запятыми — в кавычках. Так не нужны нестандартные параметры импорта, файл читается любым CSV-инструментом.
- `i18n/strings.*.translation` (результат импорта) коммитятся: иначе первый `--import` свежего клона пишет ERROR о ненайденных переводах из project.godot. После правки CSV: `--import` и закоммитить обновлённые `.translation`.
- Локаль по умолчанию — `ru` (`config/visual.json: default_locale`, fallback в project.godot), переопределение `--lang=en`.

## D-010. Форматирование чисел
- `NumFmt` (статический, `scripts/core/num_fmt.gd`) — реализация; автолоад `Fmt` — обёртка для UI.
- <1000: целое или 1 знак (`12`, `12.5`). Далее 3 значащие цифры, хвостовые нули убираются: `1K`, `1.2K`, `1.23K`, `12.3K`, `123K` … `999Dc`. Округление переносит в следующий разряд (`999.96` → `1K`, `999500` → `1M`). От 1e36 — `1.00e36` (всегда 2 знака мантиссы). NaN → `0`, ±inf → `∞`/`-∞`. Отрицательные — со знаком, без «-0».
- `Num.safe(x, fallback)`: NaN → fallback, ±inf → ±1.797e308 (максимальный конечный double), конечные числа без изменений.

## D-011. Тест-раннер ловит ошибки движка
- `tests/run_tests.gd` стартует на первом кадре `_process`, поэтому автолоады (Config, Fmt …) доступны и в `-s`-режиме.
- Через `OS.add_logger()` (класс `Logger`, Godot 4.5+) считаются ошибки движка во время каждого теста: тест с SCRIPT ERROR/push_error падает, даже если assert-ы прошли (в GDScript нет исключений). Намеренные ошибки объявляются `expected_errors = N`.
- Предупреждения GDScript (включён `untyped_declaration`) движок показывает только в редакторе: в headless-запуске и `--check-only` они не печатаются. Автоматической проверки предупреждений нет.

## D-012. Аргументы автоматизации — автолоад `DevTools`
- `--shot-time` считается в игровом времени (ускоряется `--timescale`), `--quit-after` — в реальном (страховочный таймаут). С `--shot` и без `--quit-after` игра выходит сразу после сохранения кадра. В headless-режиме скриншот пропускается с сообщением (нет рендера).

## D-013. Сборки и проверка web
- Web: шаблон без потоков (`variant/thread_support=false`) — работает на любом статическом хостинге без COOP/COEP. В экспорт явно включены `config/*.json` (не ресурсы Godot); `tests/`, `tools/`, `docs/` исключены.
- Проверка: `tools/check_web.sh` → `tools/web_check.mjs` (Node 22, встроенный WebSocket, без npm) запускает headless Chrome (SwiftShader/WebGL2), читает консоль через CDP, ждёт строку `Main scene ready`, снимает скриншот. Загрузка ~4 с. Простой `google-chrome --screenshot --virtual-time-budget` не годится: компиляция wasm не двигает виртуальное время, на снимке только полоса загрузки.
- Windows: один exe со встроенным pck (`embed_pck`), `application/modify_resources=false` — rcedit на Linux нет, поэтому иконка и версия в exe не прописываются. Проверить запуск exe в контейнере нельзя (нет Windows/wine).

## D-014. Палитра: 32 цвета рампами
- `tools/art/palette.py` — источник истины: soot(4), iron(4), brass(4), copper(4), steam(4), teal(3), ember(3), verdigris(3), parchment(3); рампы от тёмного к светлому, имена `рампа_индекс`.
- `gen_art.py` экспортирует `config/palette.json` и `assets/sprites/palette.png` и падает, если спрайт использует цвет вне палитры.
