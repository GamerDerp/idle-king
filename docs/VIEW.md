# VIEW — экран игры (часть C2)

Слой отображения: `scripts/view/`, сцена `scenes/main_game.tscn` (главная сцена проекта).
Вид **читает** ядро каждый кадр (`core.battle.*`, `core.mods`, `core.state`) и **разбирает события**
(`core.drain_events()`), но никогда не меняет правила игры: покупки — только через `core.buy()`,
вызов босса — `core.call_boss()`. Все визуальные константы — в `config/visual.json` → `game_view`
(в коде нет чисел баланса). Тексты — `i18n/strings.csv`, числа — `Fmt.num`.

## Слои (порядок отрисовки снизу вверх)

```
MainGame (Control, тема main_theme)            scripts/view/main_game.gd
├─ ColorRect фон
├─ Shake (Node2D — трясётся целиком, шаг 2 px)
│  ├─ BattleView (Node2D, ×2, смещение под полосу ресурсов; арт-пиксели)   battle_view.gd
│  │  ├─ фон региона (manifest.regions[n].bg), вода рва, MoatFx «water» (пузыри), трубы, «Топка рва» (R2),
│  │  │  Wall (y-sort: башни в визуальных слотах + Король), дым труб, `steam_curtain` (один спрайт, дышит
│  │  │  альфой), MoatFx «steam» (гребень пара над берегом)                               moat_fx.gd
│  │  ├─ DecalLayer (опалины, лужи кипятка, `mole_mound` под землёй)                  decal_layer.gd
│  │  ├─ Units (y-sort: враги — пул AnimatedSprite2D с тенью)
│  │  ├─ FxLayer (_draw: снаряды, анимации, частицы, конусы, искры, линза, полоски HP, «новый!») fx_layer.gd
│  │  └─ `steam_wisps` над берегом (выше всего на поле; дрейфуют с берега на край поля и гаснут)
│  └─ PopupLayer (_draw, экранные px: числа урона, добыча, подписи)          popup_layer.gd
├─ Hud (полоса ресурсов с целью и «?», тонкая полоса босса, счётчик рва, один тост, баннеры,
│        компактная подсказка врага, справка-глоссарий)                    hud.gd
├─ ShopPanel (TabContainer справа: «Цеха», «Карта»; сортировка карточек)    shop_panel.gd
├─ MapScreen (M1: полноэкранная «Карта завоеваний» под полосой ресурсов)    map_screen.gd
├─ ChoiceOverlay (широкое сравнение двух веток выбора)                       choice_overlay.gd
└─ LootFly (_draw поверх всего: летящая добыча к счётчикам, искры кнопок)   loot_fly.gd
ViewKit (RefCounted) — общий конфиг, палитра, координаты, тексты «было → станет»  view_kit.gd
```

Координаты: ядро = экранные пиксели 1280×720. Арт = `(экран − (0, 40)) / 2` (`kit.to_art`, `kit.to_screen`).
Движущиеся спрайты ставятся в целые арт-пиксели; числа/иконки в экранном слое — на чётные пиксели.

## Поток кадра (`MainGame._process`)
1. Курсор → `core.set_cursor()` (если не играет бот). 2. События → отклик (`_on_event`).
3. `BattleView.update_view()`: башни (новые падают в слот), враги (пул по uid), Король, пар завесы.
4. Подсказка врага под мышью, тряска, замедление. 5. Раз в `ui_refresh` (0.15 с) — тексты Hud и панели.

## Отклик на события (кратко)
| Событие | Что видно |
|---|---|
| `enemy_hit` | светлая вспышка 1–2 кадра (`scripts/view/shaders/hit_light.gdshader`: спрайт осветляется, тени видны — не силуэт; не чаще 0.1 с), сдвиг на 1 px, искры по типу урона, число (слияние частых попаданий) |
| `enemy_dot` | число пара только для завесы и луж; ошпаривание — пар над врагом |
| `lens_tick` | искры и пар в кольце; одно число на линзу (слияние 0.6 с) |
| `enemy_killed` | `scrap_burst` + обломки с отскоком, «+N» у места, монеты/чертежи летят к счётчику (он подпрыгивает, «+N» под ним) |
| `enemy_fell_in_moat` | `*_fall` + `splash` + пар + кольцо пузырей + «буль!», счётчик «в рву» мигает |
| `projectile_fired` / `cone_fired` | кадр выстрела, откат на 1 px, дым у дула; конус пара |
| `shell_exploded` | `explosion`, частицы, опалина (гаснет 4 с), тряска (меньше у осколков) |
| `purchased` / `tower_built` | башня падает в слот, пар, вспышка, тряска; у улучшения — искры на башнях и «Урон 3 → 4.2» |
| `milestone` / `tier_up` | смена спрайта уровня, латунное кольцо искр, крупная подпись «Двойной выстрел!», тост с описанием |
| `unlocked` | пергаментный тост «Новое!» (иконка + текст); регион — баннер |
| `boss_*` | полоса здоровья сверху, баннеры входа/отступления/победы, фонтан шестерёнок, короткое замедление; у Бура отступление — свой спрайт `retreat` (пятится вправо, дымит), под баннером подсказка «Броня погасила ~N урона: бей навесом, взрывами, линзой» (N считает вид по `armored`-попаданиям) |
| `enemy_hit` + `armored` | кадры `hit` у Бура (искры по плите), жёсткие латунно-железные искры у лба, «броня» на плашке (не чаще `fx.armor_label_every`) |
| `enemy_hit` + `shielded` | медные искры по шлему, «шлем» (раз в 5 с на водолаза и раз в 1.5 с на всё поле) |
| `enemy_shield_broken` | `diver_helmet_break` + осколки, «шлем сбит!»; дальше водолаз идёт `diver_bare_walk` (и падает `diver_bare_fall`) |
| `enemy_emerge` (forced) | облако земли, «выбит!» (одно на поле в 1.5 с — сейсмический заряд выбивает десяток кротов) |
| `enemy_charge` | пыль из-под гусениц, «рывок!», лёгкая тряска; пока `charging` — шлейф пыли |
| `enemy_killed` голема | `golem_split` (`enemy_sprites.*.death`) + угли вместо обломков; угольки — уже в ядре |
| `chain_fired` | кадр разряда теслы, звенья `chain_lightning` от дула по всем целям, `tesla_arc` на каждой |
| `ricochet` | `bounce_spark` на отскоке, пунктирный след к следующей цели; ядро — `ricochet_ball` |
| `geyser` | три `geyser` + `splash` + пар, двери «Топки рва» вспыхивают (`moat_furnace_hot`) |
| `drill_ram` | бур (`fx.drill_ram_sprite`, развёрнут вправо) едет по полосе от рва до `x_end`, борозда, пыль, тряска |
| `producer_output` | угли выпрыгивают из шахты во дворе, над ней «+6 уголь» / «+300 шест.» с иконками на плашке, добыча летит в счётчики |
| `enemy_status` stun | искры над головой; пока `stun_t` — две звёздочки кружат, анимация стоит |

Правила чисел (критика референса — «числа сливаются»): частые попадания по одному врагу сливаются в одно
растущее число; новое число ставится вверх / вбок / **вниз** (у верхнего края только вниз и вбок) так, чтобы не
накрыть ни одно живое число ни сейчас, ни когда оба доплывут вверх (`_hits_at`: проверка в t=0 и t=rise_time), с
зазором `popup.gap_x` (12 px) / `gap_y` — «193» рядом с «66» не читается как «193.66»; если чистого места нет —
обычное попадание или добыча сливается с ближайшим числом своего типа или пропускается (криты и подписи ставятся
всё равно); выросшее при слиянии число сдвигается на свободное место рядом (`_settle`), а если места нет — мешающие
простые числа сразу гаснут. Числа живут в поле: не выше `bar_height + popup.top_margin` (под полосой босса), не левее
рва (`popup.left`). Не больше `popup.max` (20), крупных критов не больше `popup.max_big_crits`; числа
непрозрачны и гаснут за 0.12 с; цвет = тип урона (легенда — «?»); значения ≥ 1 округляются, счётчики ≥ 10 — целые,
дробная добыча копится и всплывает целыми.

## Интерфейс (C2 итерация 2)
- Все координаты HUD — `game_view.hud` (полоса босса, счётчик рва, тост, баннер, подсказка, глоссарий).
- Цель живёт в полосе ресурсов (не закрывает поле); полоса босса — тонкая, над полосой врагов (y ≥ 130).
- «+N» у счётчика — тёмная плашка с иконкой ресурса и числом цвета ресурса, свисает под плиткой (под полосой
  босса, если та открыта), только для необычной порции (≥ 2.5 × доход/с); зелёный «+X/с» не пропадает. Доход
  < `hud.income_min` (0.05/с) не показывается («+0/с» не бывает), < 0.1/с — с двумя знаками.
- Подсказка врага: курсор — оружие, поэтому она появляется, только когда мышь замерла на `hud.tip.delay`
  (0.6 с) или зажат Alt, и пропадает при движении; враг выбирается один раз и подсказка идёт за ним.
  Легенда цветов урона — в справке «?».
- Тосты — по одному, очередь, у правого края поля внизу. Покупка узла «только числа» — тост с «было → станет»;
  улучшение башни — короткая подпись на тёмной плашке рядом с башнями.
- Карточки: доступные и новые сверху, башня на пределе — одна строка внизу; порядок не меняется, пока мышь над
  панелью. Выбор «одно из двух» — компактная карточка → «Сравнить и выбрать» → ChoiceOverlay.
- Тексты карточек не обрезаются «…»: имена, уровни и «ур. N: …» переносятся на вторую строку. Цена — каждый
  ресурс своей иконкой и полным числом (уголь никогда не прячется). Каждая недоступная по деньгам карточка
  говорит, сколько ждать: «~14с» по текущему доходу, а пока дохода нет (первая башня) — «ещё 3».
- «Было → станет» (`ViewKit.diff_lines`) покрывает каждый тип эффекта ядра: статусы — сила и длительность
  («Ошпаривание 0% → 60% · 3с») у башен, линзы и механизмов; сила крита, искра крита, ступень башни, число линз,
  добыча/чертежи со всех врагов (одна строка вместо строки на каждого врага), «Всё оружие» (одна строка вместо урона
  каждой башни). Качественные эффекты (открытия, наводчик, бой с боссом) — строкой «• новое». Тест
  `test_every_effect_type_renders_a_row` проходит по всем эффектам `map.json`, улучшений, вех и наград боссов.
- Стена: три колонки на галерее (`game_view.wall`), в колонке шаг 30 px, средняя колонка — в промежутках;
  у башен 3 кадра выстрела, дуло и `muzzle_smoke` — из манифеста (`muzzle`). Глубина: колонка дальше поднята
  (`columns.<c>.dy`: средняя −4, задняя −10 арт-px), чтобы ствол мортиры выглядывал над клепальщиком, и чуть темнее
  (`dim`: 0.9 / 0.8).
- Ров живой и без падений: пузыри на воде, гребень пара (`steam_puff`) над ближним берегом, сносимый на поле
  (редкий без завесы, густой с ней — так видна и покупка завесы), клочья `steam_wisps` дрейфуют на край поля,
  спрайт завесы «дышит» альфой (`game_view.moat`).
- «новый!» над только что пришедшим врагом прижимается внутрь поля (не режется панелью).

## V3: регион 2–3 на экране
- Спрайты всех врагов/башен — `game_view.enemy_sprites` (`walk`, `fall`, `shadow`, `pieces`; R2+: `hit`, `retreat`,
  `bare_walk`/`bare_fall`, `shield_break`, `death`, `burrow`/`emerge`/`mound`) и `tower_sprites`. Состояние спрайта
  врага выбирает `BattleView._enemy_anim` каждый кадр (кадры попадания по броне → без шлема → ходьба).
- Значки статусов над головой (запечены в текстуры с тёмным контуром 1 px, один draw на значок): оглушение — две
  звёздочки кружат, замедление — бирюзовый шеврон, ошпаривание — капля пара. У водолаза под полоской здоровья —
  медная полоска шлема. Приманка — до трёх мешков на спине.
- Лужи: у котлобоя (`puddle_burning.<башня>`) — `burning_puddle` поверх лужи (тайлами, без масштаба), смоляная
  (со статусами) — тёмная, остальные — кипяток.
- Цеха (`producer_sprites.<id>`) встают в `yard_slots` двора, когда открыты; под зданием латунный манометр цикла
  (`core.producer_progress`), полный — краснеет.
- «Топка рва»: off — регион 2 открыт; warm — завеса шире базовой; hot — есть гейзеры или только что был выброс.
- Фон поля — по самому новому открытому региону (`manifest.regions`), смена — плавная (`region_fade`, 2 с).
- Пароструй: спрайт `steam_cone` у дула + клубы `steam_puff` по реальной дальности (без плоского треугольника).
- Карточки: при цене в нескольких ресурсах «~1м 03с» уходит под цену (карточка не шире панели).
- `--fx-demo` — раз в секунду проигрывает все эффекты R2/R3 на живом поле (скриншоты редких моментов).

## M1: «Карта завоеваний» (`MapScreen`, `scripts/view/map_screen.gd`)
Открывается клавишей **M**, кнопкой «Открыть карту (M)» во вкладке «Карта» и кликом по цели в полосе ресурсов (если узел
ещё не по карману — карта открывается на нём). Закрывается M / Esc / «К бою». Бой идёт дальше (ядро тикает), его слой
не рисуется; полоса ресурсов с доходом остаётся сверху, внизу слева — живая строка «Бой идёт: врагов N, в рву M».
- Мир — `map_bg` (2400×1700 арт-px) в узле с целым масштабом 1–3 (`game_view.map.zoom`, по умолчанию 2); узел карты
  стоит в `origin + pos × scale` из `config/map_layout.json`. Слои: фон → дороги (`map_road_dot` каждые 7 px, кадр
  закрыта/открыта/пройдена; перерисовка только при смене состояний) → маркеры (`node_<kind>`, кадр = состояние; цеха —
  `node_producer` по `map.effect_sprites`) → туман регионов (`map_fog_rN` + дрейфующие `map_fog_wisp`) → подписи
  регионов (Kotel title, «взято N из M»; над туманом — «неизведанно» и чернильный силуэт хозяина региона,
  `map.region_silhouettes`) → эффекты.
- Состояния маркера: закрыт (родитель не куплен; бледная тушь), доступен (латунная дуга бежит по кругу; по карману —
  ещё и латунный огонёк вокруг; не по карману — приглушён и подписан «~1м 40с»), куплен (латунь + печать; у
  многоуровневых — точки уровней), взят полностью (позолота), закрыт выбором (перечёркнут). Пара выбора связана
  пунктиром, между ними — знак-развилка `node_choice` (или «или», если знаку тесно).
- Наведение — пергаментная записка (`MapCard`): имя, тип, ур. x/max, что нового, «было → станет», цена иконками,
  «~время», «клик — купить, удерживай — ещё уровни»; закрытому — «Сначала: «…»», трофею — «Награда за победу: …».
- Клик покупает (через `ShopPanel.buy`), удержание (0.35 с) — ещё уровень каждые 0.12 с. Узел выбора открывает
  ChoiceOverlay на весь экран с предупреждением «до Великой Переплавки».
- Камера: перетаскивание, WASD/стрелки, края экрана, колесо (целый зум вокруг курсора), «К крепости» (на крепость
  и ближайшую цель), «+»/«−».
- «Что купить»: латунная стрелка с подписью над узлом цели (`core.next_goal()`), иначе над самым скорым доступным.
- Отклик: каждая новая покупка (и сделанные, пока карта была закрыта — при открытии, по очереди) — клякса
  `map_ink_splat`, затем сургуч `map_stamp`, по дорогам к детям бегут `map_spark`. Открытие региона — фронт
  `map_fog_burn` идёт от крепости через регион, туман редеет и исчезает, баннер «Открыт регион: …».
- Картуш «Долина покорена на N%» (`map_progress_frame/fill`, ×2): (куплено + закрыто выбором) / все узлы.
- `--map-dummy=250` — карта из 250 фальшивых узлов по 8 регионам (читаемость и скорость; тест `test_conquest_map`
  держит кадр карты < 8 мс; на деле ~0.6 мс), `--open-map=<с>`, `--map-zoom=<1..3>`, `--map-focus=x,y` (арт-px),
  `--mouse=map-hint` (курсор на подсказке — видна записка).

## Как добавить нового врага
1. Нарисовать `<имя>_walk` (4 кадра, смотрит влево, якорь — ноги; основной цвет с контрастом ≥ 2:1 к `dust_1`)
   в `tools/art/*.py`, зарегистрировать в `build_units` (`tools/art/gen_art.py`) — `<имя>_fall` получится сам.
2. `python3 tools/art/gen_art.py && godot --headless --path . --import`.
3. В `config/visual.json` → `game_view.enemy_sprites.<тип>`: `walk`, `fall`, `shadow` (`shadow_s|m|l`), `pieces` (цвета обломков).
4. Тест `tests/test_view.gd` проверит, что у каждого врага из `enemies.json` есть спрайты.

## Как добавить новую башню
1. Спрайты `<база>_t0..t2` (32×40, 2 кадра: покой/выстрел, ствол вправо, якорь (16, 37)) — `tools/art/`, `build_towers`.
2. `game_view.tower_sprites.<тип>` = база, `game_view.muzzle.<база>` = дуло относительно ног (арт-px).
3. Ряд башни (`towers.json` → `row`) выбирает колонку стены: `game_view.wall.row_column`; места — `wall.columns`.
4. Новый вид снаряда: ветка в `FxLayer._draw_projectiles` (сейчас `bullet`, `rivet`, `shell`; конус — событием).

## Отладочные аргументы (после `--`)
`--debug-view` (старая отладочная сцена), `--bot[=real|idle] --ff=<с>` (см. CORE.md), `--mouse=enemy` (курсор
следует за врагом, раз в 1.2 с, затем замирает: ручная линза и подсказка), `--give=gears:500,blueprints:40`
(добавить ресурсы; в доход/с не попадает), `--buy=id,id --buy-at=<с>` — нажать кнопки покупки; id с префиксом:
`tower:<тип>` (башня), `upg:<id>` (улучшение за шестерни), `node:<id>` (узел карты), `compare:node:<id>` (открыть
сравнение выбора); `--tab=<0|1>` (вкладка панели), `--fx-demo` (эффекты R2/R3 раз в секунду), `--open-map`/`--map-dummy`/`--map-zoom`/
`--map-focus` (карта, см. M1), `--stress` (держать ~150 врагов и ~300 снарядов), `--perf=<с>` (замер кадра, вывод
`PERF ...` и выход), `--shot-burst=<n> --shot-interval=<с>` (серия скриншотов, DevTools).

Пример: `xvfb-run -a -s "-screen 0 1280x720x24" godot --path . --rendering-driver opengl3 --audio-driver Dummy -- --bot --ff=300 --shot=shots/5min.png --shot-time=5`.

## Производительность
Всё массовое (снаряды, частицы, анимации эффектов, числа, летящая добыча) рисуется в нескольких `_draw` —
один canvas item на слой, без узлов на эффект; враги — пул узлов. Под `--stress` (164 врага, ~310 снарядов,
24 числа, 450 частиц) скрипты вида тратят ≈ 6 мс на кадр, ядро+бот ≈ 6 мс; остальное время кадра под xvfb —
программный рендер llvmpipe (≈ 20 мс даже на пустом экране), на настоящей видеокарте его почти нет.
Ограничители: `FxLayer.MAX_PARTICLES` (450; искры попаданий — только до `particles.low_prio_share` = 60%),
`MAX_ANIMS` (180), `popup.max` (20; в толпе — `popup.crowd`: слияние в радиусе, мелкие попадания пропускаются),
`loot.max_flying`.
