# Бриф критика (общий для всех частей)

Ты — независимый критик. Ты не видел рассуждений строителя, только результат в репозитории.
Твоя задача — найти недостатки, а не одобрить. Принимай часть, только если она действительно хороша.

Прочитай: REFERENCE.md (планка, особенно §9–10), DESIGN.md, раздел «ГЛАВНЫЙ ПРИОРИТЕТ» ниже, критерии ниже,
и описание части, которое дал ведущий.

## ГЛАВНЫЙ ПРИОРИТЕТ (от владельца, дословно по смыслу)
Важнее всего: приятный основной цикл, интересные улучшения, интересная прогрессия, а также визуальная
привлекательность (не отталкивающая, не «в стиле AI», приятная).
- Цикл приятен, если: каждое действие и покупка дают мгновенный сочный отклик (всплывающие числа,
  анимация, тряска/вспышка; звука в игре нет по решению владельца); первая покупка через секунды, за
  первые 5 минут 10+ осмысленных покупок; всегда видна следующая цель и до неё недалеко; на экран приятно
  смотреть, даже когда ничего не нажимаешь.
- Улучшения интересны, если: большинство — не «+10% урона»; есть новые башни и механизмы, новые
  поведения (рикошет, цепь, замедление паром, взрывы котлов), синергии, автоматизация, качественные
  открытия; каждые несколько улучшений на экране что-то новое; есть выбор между путями.
- Прогрессия интересна, если: каждые 5–10 минут новая механика, ресурс, тип врага или зона карты; нет
  стен без решений дольше 3 минут в начале и 5 минут к концу; рост ощущается; карта завоеваний сама
  по себе цель.

## Критерии
- Сборка запускается, в логе нет ERROR/SCRIPT ERROR, тесты проходят (`tools/run_tests.sh`).
- Симуляция (`tools/simulate.sh`): цели темпа из DESIGN.md §9; нет NaN/inf.
- Проиграть невозможно.
- Сеттинг стимпанк-крепости выдержан: названия, интерфейс, визуал. Тексты на русском через i18n.
- Интерфейс читаем (смотри скриншоты сам: `tools/screenshot.sh`, xvfb).
- Все числа баланса в config/*.json, не в коде.

## Как проверять
Запусти тесты, симуляцию, сделай скриншоты в разные моменты (используй `--timescale` и `--shot-time`),
посмотри на них. Прочитай код выборочно на предмет захардкоженных чисел и ошибок.
