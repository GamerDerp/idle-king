# ART — пиксель-арт, шрифты, тема интерфейса

Весь арт рисуется кодом (`tools/art/*.py`, Python + PIL). Чужих ассетов и шрифтов нет.
Обзор для критиков: `docs/art/font_specimen.png`, `docs/art/sprites_sheet.png`, `docs/art/battlefield_bg_2x.png`;
живой макет — `scenes/art_preview.tscn` (см. ниже).

## Перегенерация
```
python3 tools/art/gen_art.py          # всё: палитра, спрайты, манифест, шрифты, тема, листы для обзора
godot --headless --path . --import    # импорт новых PNG/.fnt
```
Генерация детерминирована (одинаковый результат при повторном запуске), PNG и `.fnt` коммитятся.
Скрипт падает, если любой спрайт или текстура темы использует цвет вне палитры.

| Файл | Что внутри |
|---|---|
| `palette.py` | палитра (рампы, тёмный → светлый) |
| `pixel.py` | Canvas: рисование по именам цветов, контур, ASCII-спрайты (легенда в docstring) |
| `layout.py` | геометрия поля боя в арт-пикселях (уходит в манифест) |
| `sprites_world.py` | земля, дорога, ров, пар, стена, надвратная башня, бастион, трубы, фон поля |
| `sprites_units.py` | враги региона 1 и Король (ASCII-карты) |
| `sprites_towers.py` | башни × 3 уровня |
| `sprites_r2.py` | латник, подручный вожака, крот-шахтёр; башни Пароструй и Котлобой (C2) |
| `sprites_fx.py` | снаряды, эффекты, монета, иконки, Паровая линза, тени |
| `font_glyphs.py`, `font_gen.py` | пиксельный шрифт «Kotel» (глифы вручную) → BMFont |
| `ui_gen.py` | текстуры 9-slice и `themes/main_theme.tres` |

## Палитра
- 35 цветов: 32 базовых (D-014) + рампа `dust` (3 цвета земли, D-031). Имена `рампа_индекс`, индекс 0 — самый тёмный.
- В коде цвет только по имени: `Config.color("brass_3")` (`config/palette.json` генерируется).
- Правила: свет сверху-слева (блики на верхних/левых гранях, тени и падающие тени — вниз-вправо);
  контур `soot_0` у персонажей, башен, иконок; без градиентов и «свечения»; дизеринг почти не используется.
  Полупрозрачность — только у пара/дыма/контактных теней (цвет всё равно из палитры).
- **Читаемость врагов**: основной цвет врага (самый частый, без контура) должен давать контраст яркости
  ≥ 2:1 к `dust_1` (земля поля). `gen_art.py` проверяет это и падает. Земля — рампа `dust`, поэтому враги
  в неё не красятся: Бродяга — `verdigris` (2.98:1), пёс/Вожак/Старьёвщик — `copper_3` (2.78:1), тележка —
  латунь. Персонажам добавляется светлый 1-px ободок сверху-слева (`pixel.rim_light`).
- Облака (дым, пар, взрывы) — `pixel.cloud`: тело + 3–5 «долей» с собственной светотенью (завитки на стыках)
  и рваный хвост; идеальных кругов нет.
- Роли: `iron` — сталь и стена; `brass` — отделка, ценное, кнопки; `copper` — ржавчина, дерево, медь;
  `teal` — кипящая вода; `steam` — пар; `ember` — огонь, урон, королевский красный; `verdigris` — патина, «+»;
  `parchment` — бумага, светлый текст; `soot` — фон и контур; `dust` — земля поля.

## Масштаб
- Окно 1280×720. Мир и интерфейс показываются с целочисленным масштабом **×2** (1 арт-пиксель = 2×2 экрана).
- Спрайты лежат в 1× — узел мира масштабируется на 2 (`SpriteLib.scale()`).
- Текстуры темы уже сохранены в 2× (`themes/ui/*.png`), поэтому все поля/отступы темы — в экранных пикселях.
- Фильтр текстур — nearest (настройка проекта). Двигающиеся спрайты ставить в целые арт-координаты (`pos.round()`),
  иначе появляются полупиксели.

## Поле боя (арт-пиксели, `manifest.battlefield`)
Фон `battlefield_bg` 450×340 (= 900×680 на экране) ставится в экранные (0, 40) под полосой ресурсов.
Слева направо: двор 0–55, стена (галерея 56–87 с башнями, зубцы 88–95, внешняя грань 96–107),
ров 108–137 (анимированная вода `moat_water` поверх, тайл 30×64), берег 138–145, поле от 146.
Дорога — `road_samples` (x → центр y), ширина ±17. Дорога упирается в обломанный мост, на надвратной
башне поднят мост. Вдоль западного края рва идёт латунная паровая магистраль (`steam_pipe`, тайл 14×18,
сопло 4×5 на каждые 18 px, вентили) — из каждого сопла бьёт струя и поднимается пелена пара (`steam_sheet`),
наклоняясь к востоку; пелены перекрываются в сплошную завесу. Восточный берег — каменная подпорная стенка
(освещённая грань, плиты, тень на поле), у её подножия вода темнее. Поэтому враги до стены не доходят:
они срываются в кипяток (`*_fall` + `splash`).
Порядок слоёв: фон → вода `moat_water` → `steam_pipe` (поверх воды) → башни/Король → `steam_sheet` → враги/эффекты.
Композиция поля: тёмные гряды с кустами сверху и снизу ведут взгляд к дороге; 5 светлых «такыров» с гладкими
краями; реквизит собран в 4 группы (котёл+лом+трава; колесо+камни; сухое дерево+валун+воронка; воронка+камни);
вдоль обочин — кочки и камни.
В манифесте также: `tower_slots` (точки ног башен), `king_pos`, `steam_vents_y`, `smoke_points`, `gate_top`.
Проекция «3/4 сверху»: вертикальные предметы растут вверх по экрану, у стены видна её затенённая восточная грань.

## Спрайты и манифест
`assets/sprites/<категория>/<имя>.png` — кадры анимации лежат горизонтальной полосой.
`assets/sprites/manifest.json`: `имя → {file, frame_size, frames, fps, anchor, loop, note}`; `anchor` — точка
опоры в пикселях кадра (ноги персонажа, низ основания башни, центр линзы).

Категории: `world` (фон, тайлы земли/дороги, ров, пар, дым, стена, башни крепости, трубы, пропсы),
`enemies` (`scavenger_walk` Бродяга, `junk_cart_walk` Старьёвщик, `hound_run` Ржавый пёс, `boss_walk` Вожак,
`knight_walk` Жестяной латник, `guard_walk` Подручный вожака, `mole_walk` Крот-шахтёр),
`characters` (`king_idle`, `king_tea`), `towers` (`rifle|riveter|mortar|steam_jet|boiler` × `_t0` железо / `_t1` латунь /
`_t2` золочёная с трубами и вымпелом; кадр 0 — покой, 1 — выстрел), `projectiles` (`bullet`, `rivet`, `shell`),
`fx` (`hit_spark`, `explosion`, `steam_puff`, `splash`, `scrap_burst` — обломки при убийстве, `shadow_s|m|l`),
`enemies/*_fall` (3 кадра: враг уходит под воду, якорь — линия воды), `pickups` (`gear_coin` — выпавшая
монета, `gear_coin_fly` — 5 кадров, маленькая, летит к счётчику, `blueprint`),
`icons` (16×16 `res_gears|blueprints|coal|copper|springs|ether|seal`, 12×12 `dmg_impact|steam|spark|blast`),
`cursor` (`steam_lens`, 3 кадра мерцания). Враги смотрят влево, пушки — вправо.

В коде — `SpriteLib` (`scripts/view/sprite_lib.gd`):
```gdscript
var e := SpriteLib.make("hound_run")        # AnimatedSprite2D, играет, начало координат = anchor
e.position = Vector2(300, 190)              # арт-пиксели внутри узла мира (scale 2)
icon.texture = SpriteLib.texture("res_gears")   # кадр 0 (AtlasTexture для полос)
var lay := SpriteLib.layout()               # геометрия поля
```
Тень под юнитом: дочерний `SpriteLib.make("shadow_s")` с `show_behind_parent = true`, смещение (+1, 0).
`SpriteLib.texture()` кэширует AtlasTexture (один объект на кадр).
Смерть: убит → `scrap_burst` (+ числа и монеты); дошёл до рва → `<враг>_fall` + `splash` у берега.
Король: `king_idle` (4 кадра: дыхание, кивок, петля), раз в несколько секунд — `king_tea` (6 кадров, без петли).
Башни: уровни отличаются силуэтом — t0 без трубы, t1 латунная отделка и короткая выхлопная труба,
t2 высокая труба с латунным венцом, увеличенный корпус и сдвоенное оружие (2 ствола / 2 магазина / толстая
мортира) + вымпел. Вид меняет спрайт уровня на рубежах улучшений.

### Вспышка попадания
`assets/shaders/hit_flash.gdshader` (canvas_item): при `flash > 0.5` силуэт заливается одним цветом палитры
(`flash_color`, по умолчанию `steam_3`), альфа сохраняется — без смешивания и свечения.
```gdscript
var mat := ShaderMaterial.new(); mat.shader = preload("res://assets/shaders/hit_flash.gdshader")
enemy.material = mat                       # материал на врага (уникальный, или общий + instance uniform)
mat.set_shader_parameter("flash", 1.0)
create_tween().tween_method(func(v: float) -> void: mat.set_shader_parameter("flash", v), 1.0, 0.0, 0.08)
```
Крит/босс — `flash_color = ember_2`. Не мигать чаще раза в 0.1 с на одного врага.

### Всплывающие числа
Шрифт `fonts/kotel_number.fnt` — bold с «запечённым» 1-px чёрным контуром (белая заливка тонируется
`font_color`, контур остаётся тёмным; тень не нужна). В узле мира (scale 2) — `font_size = 12`, в UI — 24.
Цвет по типу урона: Удар — `parchment_2`; Пар (и линза) — `teal_2`; Искра — `brass_3`; Взрыв — `ember_2`;
крит — тот же цвет, `font_size` 24 в мире (×2) и «+» в конце не нужен; добыча: шестерни `+12` — `brass_3`
рядом с иконкой, чертежи — `steam_3`. Движение: вверх на 9 арт-px за 0.6 с, затем исчезнуть (без масштабирования,
координаты округлять до целых арт-пикселей); одновременно на экране ≤ ~30 чисел, мелкие суммировать.
Однократные эффекты (`loop: false`): `animation_finished.connect(node.queue_free)`.
Манифест — не ресурс Godot: в `export_presets.cfg` он добавлен в `include_filter`.

## Шрифт «Kotel»
Нарисован вручную (`tools/art/font_glyphs.py`): ASCII, полный русский алфавит с Ёё, цифры, пунктуация,
`+ − × ÷ ± % → ← ↑ ↓ / : ( ) [ ] { } « » „ “ ” — – … № ° · • ∞ @ # $ & *`. Пропорциональный.
Прописные 7 px, строчные 5 px, выносные 2 px.

| Файл | Размер (`size`) | Использовать с `font_size` | Назначение |
|---|---|---|---|
| `fonts/kotel_regular.fnt` | 12 | **24** (×2) | основной текст (шрифт темы по умолчанию) |
| `fonts/kotel_bold.fnt` | 12 | **24** (×2) | кнопки, вкладки, имена, цены, числа урона |
| `fonts/kotel_title.fnt` | 16 | **32** (×2) | заголовки (прописные 11 px) |
| `fonts/kotel_number.fnt` | 12 | 12 в мире / 24 в UI | всплывающие числа: bold + чёрный контур |

Формат — BMFont (текстовый `.fnt` + PNG-атлас; у PNG в `.import` — `importer="skip"`, D-038), импортёр Godot `font_data_bmfont`, в `.fnt.import`
`scaling_mode=1` (только целочисленное масштабирование). Размер шрифта всегда кратен `size`
(12/24/36, 16/32/48), иначе Godot масштабирует не целочисленно и буквы «плывут». Внутри узла мира
(scale 2) — `font_size = 12` (bold) для всплывающих чисел. Тень текста — смещение 2 px (1 арт-пиксель).
Новые символы: добавить глиф в `font_glyphs.py` → `gen_art.py` → `--import`.

## Тема интерфейса
`themes/main_theme.tres` (генерируется, вручную не править). Назначить корневому Control сцены: `theme = main_theme.tres`.
Шрифт по умолчанию — Kotel Regular 24.
- `Panel` / `PanelContainer` — клёпаная тёмная плита с латунной рамкой.
- `Button` — латунная пластина толщиной 2 px; hover светлее; pressed проседает на 1 арт-пиксель (текст сдвигается на 2 px);
  disabled — железо. Шрифт кнопок — bold, тёмный текст.
- `TabContainer`/`TabBar` — вкладки; выбранная сливается с панелью и имеет латунный верх.
- `ProgressBar` — манометр: латунная трубка с делениями, заливка жар (`ember`) со стрелкой-бликом;
  вариации `SteamGauge`, `TealGauge`.
- `TooltipPanel`/`TooltipLabel` — пергамент, тёмный текст (стандартные подсказки Godot).
- `VScrollBar`/`HScrollBar`, `HSeparator` (железная полоса с латунной заклёпкой).
- Вариации `PanelContainer` (`theme_type_variation`): `CardPanel` (холодная тёмная плита), `CardAffordable`
  (тёплый латунно-коричневый фон, двойная латунная кромка, 4-лучевые искры на углах — «можно купить»;
  у недоступной карточки иконку в нише приглушать: `modulate = Color(1, 1, 1, 0.45)`), `PlainPanel`, `TopBar` (полоса ресурсов), `ResourcePlate`,
  `InsetPanel` (ниша под иконку), `Badge` (красный счётчик), `TooltipLikePanel` (пергамент для своих подсказок).
- Вариации `Label`: `HeaderLabel` (title 32, латунь), `BoldLabel`, `PriceLabel` (латунь), `BadLabel` (жар, «не хватает»),
  `GoodLabel` (патина, «+25%»), `DimLabel` (серый), `CounterLabel`, `InkLabel` (тёмный на пергаменте).
- Иконки 16×16 в интерфейсе — `TextureRect` 32×32 (×2), `TEXTURE_FILTER_NEAREST`; иконки урона 12×12 → 24×24.

## Макет экрана
`scenes/art_preview.tscn` (+ `scripts/view/art_preview.gd`, тексты в `scenes/art_preview_text.json`) —
анимированный макет боя: крепость, ров с паром, дорога, враги с тенями, стрельба башен, взрывы, всплески,
линза в авто-режиме, Король с чаем, полоса ресурсов, строка цели, магазин справа, подсказка.
Не связан с ядром игры. Аргумент `--kit` показывает «витрину» темы: все состояния кнопок, манометры,
панели, вкладки, прокрутку, иконки, башни всех уровней.
```
xvfb-run -a -s "-screen 0 1280x720x24" godot --rendering-driver opengl3 --audio-driver Dummy --path . \
  res://scenes/art_preview.tscn -- --shot=shots/preview.png --shot-time=3          # макет боя
  ... -- --kit --shot=shots/kit.png --shot-time=1                                    # витрина темы
```
