# Idle King — стимпанк-крепость

Idle/инкрементальная игра про паровую крепость (Godot 4.7.2, GDScript, рендерер Compatibility).
Документы: `docs/ARCHITECTURE.md` (структура и правила), `DECISIONS.md` (журнал решений).

## Запуск
```bash
godot --headless --path . --import          # импорт ресурсов (после новых PNG/CSV)
godot --path . --audio-driver Dummy          # играть (нужен дисплей)
godot --path . --audio-driver Dummy -- --lang=en --timescale=4
godot --path . --audio-driver Dummy -- --debug-view             # старый отладочный вид
godot --path . --audio-driver Dummy -- --bot --ff=300           # бот играет, промотка на 5 минут
```

## Как играть
- Слева — крепость Короля Котлов, справа по полю идут враги. Башни на стене стреляют сами; кто дошёл до
  кипящего рва — срывается в воду без добычи («в рву: N» в полосе ресурсов).
- **Мышь — оружие**: наведи курсор на поле — Паровая линза жжёт всех в кольце. Кликать не нужно.
  Отпустишь мышь на 2 с — линза перейдёт в «авто» и будет летать сама (слабее; «наводчик» — умнее).
- Убитые враги роняют **шестерни** (башни и улучшения во вкладке «Цеха») и **чертежи** (узлы во вкладке
  «Карта»: новые враги, башни, механизмы, выборы «одно из двух»). Карточка показывает «было → станет»,
  подсвечивается, когда хватает, и пишет, сколько ждать, если долго.
- Строка над полем — **ближайшая цель**; клик по ней покупает цель, если хватает, или показывает её на карте.
- Наведи мышь на врага — подсказка: здоровье, броня/слабость, добыча, легенда цветов урона.
- Последний узел региона вызывает босса: полоса здоровья сверху; дошёл до рва — отступил, «Вызвать снова».
- Клавиши `1`/`2` — вкладки «Цеха»/«Карта». Звука в игре нет — всё видно.

## Тесты
```bash
tools/run_tests.sh                    # все тесты, код 0 = всё зелёное
tools/run_tests.sh --filter=test_fmt  # только часть
```

## Скриншот и симуляция
```bash
tools/screenshot.sh 2 shots/main.png [--timescale=10]   # кадр через 2 с игрового времени (xvfb)
tools/simulate.sh 60                                     # headless-симуляция (пока заглушка)
```

## Сборка
```bash
tools/export_web.sh       # build/web/index.html; запуск: python3 -m http.server -d build/web 8000
tools/check_web.sh        # экспорт + проверка загрузки в headless Chrome, скриншот shots/web.png
tools/export_windows.sh   # build/windows/IdleKing.exe
```

## Арт
```bash
python3 tools/art/gen_art.py   # спрайты в assets/sprites/, палитра в config/palette.json
```
